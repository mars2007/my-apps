# バリアフリー会話システム (Web版)
ブラウザのマイク機能を使って音声を文字起こしし、ローカル環境で動作する大規模言語モデル（LLM）を介して、リアルタイムで日本語校正や英語翻訳を行うWebアプリケーションです。

---

## 🛠️ 事前準備と環境構築

本システムを動作させるには、パソコンのローカル環境に **Ollama** と **Open WebUI**（Docker経由）を構築する必要があります。以下の手順に従って設定を行ってください。

### 1. Ollama のインストール

PC内でAIモデルを軽量・高速に動かすためのエンジンをインストールします。

1. [Ollama 公式サイト](https://ollama.com/) にアクセスし、お使いのOS（Windows / Mac）用のインストーラーをダウンロードします。
2. インストーラーを実行し、画面の指示に従ってインストールを完了させます。
3. インストール完了後、コマンドプロンプト（Windows）またはターミナル（Mac）を開き、本システムでデフォルト設定されているモデル（`qwen2.5`）をダウンロードするために以下のコマンドを実行します。
   ```bash
   ollama run qwen2.5
※ ダウンロードが完了し、対話モード（>>>）が表示されたら、/exit と入力して終了します。

2. Docker Desktop のインストール
Open WebUIを安全かつ簡単に起動するため、コンテナ仮想化ツールを導入します。

Docker 公式サイト から Docker Desktop をダウンロードしてインストールします。

インストール後、PCを再起動し、Docker Desktopを起動しておきます。

3. Open WebUI の設定方法
OllamaのAIモデルをWebブラウザ上で管理・接続するためのインターフェース（Open WebUI）を起動します。

コマンドプロンプトまたはターミナルを開き、以下のコマンドをコピー＆ペーストして実行します（Ollamaが同じPC内で動いている場合用）。

Bash
docker run -d -p 3000:8080 --add-host=host.docker.internal:host-gateway -v open-webui:/app/backend/data --name open-webui --restart always ghcr.io/open-webui/open-webui:main

起動が完了したら、ブラウザで http://localhost:3000 にアクセスします。

初回アクセス時は管理者アカウントの作成を求められるため、任意の名前、メールアドレス、パスワードを入力してサインインします（データは完全にローカルに保存されます）。

4. APIキーの発行と設定
本システムから Open WebUI を経由してAIモデルを呼び出すための「鍵（APIキー）」を取得します。

Open WebUIの画面左下にある自分のユーザー名（アイコン）をクリックし、「設定 (Settings)」 を開きます。

設定メニュー内の 「アカウント (Account)」 または 「APIキー (API Keys)」 セクションを探します。

「キーを生成 (Generate Key)」 ボタンをクリックし、発行された sk- から始まる文字列（APIキー）をコピーします。

🚀 バリアフリー会話システムの使い方
アプリの起動
本リポジトリの index.html をブラウザ（Google Chrome または Microsoft Edge 推奨）で直接開きます。

画面での設定項目
画面左側の「設定」カードを以下のように調整します。

エンドポイントURL: デフォルトのまま（http://localhost:3000/api/v1/chat/completions）

モデル名: Ollamaで取得したモデル名（デフォルトは qwen2.5:latest）を入力

APIキー: 前のステップで Open WebUI からコピーした sk-... のキーを貼り付けます。

接続テスト
「送信モード」の横にある 「✓ 接続テスト（/models）」 ボタンをクリックします。

正常に通じれば、ボタンの横に OK: 200 と表示されます。通信エラーになる場合は、DockerやOllamaが起動しているか、URLやAPIキーが正しいか再確認してください。

音声処理の実行
「▶ 開始（マイク）」 ボタンをクリックします。

ブラウザからマイクの利用権限を求められた場合は、「許可」 を選択します。

マイクに向かって話すと、中央の「文字起こし」の「ライブ」欄にリアルタイムで言葉が生成されます。

話し終えて一区切りつくと、その文章が「確定」欄に移動し、自動的にローカルAIへ送信されます。

画面右側の「校正テキスト」領域に、AIが処理した美しい文章（または翻訳文）がリアルタイム（ストリーム対応）で出力されます。

一時停止したい場合は 「■ 停止」、画面のログをリセットしたい場合は 「⟲ クリア」 を押してください。
(※ マイクがONの時、キーボードの スペースキー を叩くことでも開始・停止を素早く切り替えられます。)

⚠️ 注意事項
推奨ブラウザ: 音声認識エンジンにブラウザ標準の Web Speech API を使用しているため、Google Chrome または Chromium版 Microsoft Edge で動作させてください。

HTTPS化について: ページをインターネット上（GitHub Pagesなど）に公開してマイク機能を使用する場合、ブラウザのセキュリティ制限により、HTTPS（暗号化通信）環境が必須となります。GitHub Pages上で動かす場合は自動でHTTPS化されるため問題ありません。
