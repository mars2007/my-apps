開発環境・基本利用方法

1. オンライン上でのクイック起動

各カードの「起動する ➔」をクリックすると、別タブでアプリケーションが即座に起動し、Webブラウザ上でシミュレーションやゲームをお楽しみいただけます。

2. ローカル環境へのダウンロード（クローン）

プロジェクトのソースコードを手元のPCにダウンロードして実行、または編集を行う場合は、以下のコマンドをターミナルで実行してください。 

git clone https://github.com/mars2007/my-apps.git
cd my-apps

💻 動作環境および採用技術一覧

  • Frontend Web: HTML5, CSS3, JavaScript (Vanilla JS), Web Speech API (音声認識・音声合成)
  • Desktop Apps: Windows環境向けネイティブ実行ファイルパッケージ
  • External APIs: OpenAI 互換API対応、将棋エンジン（やねうら王推論ロジック）連携
  • 対応ブラウザ: Google Chrome / Microsoft Edge (各最新版推奨・デベロッパーモード対応)
