README – WebcamWipeWindow

■ アプリ概要

WebcamWipeWindow は、Webカメラ映像を
円形または矩形（フル画面）で切り抜いて表示する “ワイプ風カメラウィンドウ” です。

背景を透明にでき、講義資料・画面収録・配信などの上に重ねて利用できます。
インストール不要で、フォルダ内の WebcamWipeWindow.exe を実行するだけで動作します。

■ 必要環境

Windows 10 / 11

Webカメラ（内蔵 / USB）

64bit OS

配布フォルダ一式（exe だけでは動作しません）

■ 起動方法

ZIP を展開します。

フォルダ内の
WebcamWipeWindow.exe
をダブルクリックします。

■ 使い方
● ウィンドウの移動

ワイプウィンドウ上を 左ドラッグ します。

● サイズ変更（矩形モードのみ）

右下角にカーソルを合わせ、ドラッグするとリサイズできます。
（円形モードではリサイズ不可。常に真円となるため）

● 右クリックメニュー

ワイプウィンドウ上で 右クリックするとメニューが表示されます。

▼ サイズプリセット

Small (240×180)

Medium (360×270)

Large (480×360)

▼ 形状（Shape）

Full Rect（矩形・リサイズ可）

Circle（常に真円）

▼ 最前面

Always on top: ON

Always on top: OFF

▼ 終了

Exit → アプリを終了します。

■ 注意点

Webカメラが他のソフトに占有されている場合、映像が取得できません。
Zoom / Teams / OBS などを終了してください。

exe 単体では動作しません。フォルダ丸ごと保持してください。

■ フォルダ構成（必須ファイル）
WebcamWipeWindow/
 ├─ WebcamWipeWindow.exe      ← 実行ファイル
 ├─ app/
 │    ├─ WebcamWipeWindow.jar
 │    └─ lib/（各種依存ライブラリ）
 └─ runtime/（Java 実行環境）
